# 1816 – Das Jahr ohne Sommer (YouTube-Fassung, Entwurf)

Storyline A „Die Kette“. 51 Szenen, ca. 830 Wörter → mit Wills Tempo und Pausen ca. 7 Minuten.
Zahlen werden für die Stimme ausgeschrieben.

| Szene                                  | Sprechertext                                                                                                                        |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **Einstieg**                           |                                                                                                                                     |
| 01                                     | Stell dir vor, es ist Juni. Du willst ins Freibad. Und draußen … schneit es.                                                        |
| 02                                     | Genau das ist passiert. Im Jahr achtzehnhundertsechzehn. Man nennt es: das Jahr ohne Sommer.                                        |
| 03                                     | Ernten verfaulten, Brot wurde unbezahlbar, Menschen wanderten aus. Und am Ende entstand sogar ein Monster.                          |
| 04                                     | Und alles begann mit einem einzigen Berg. Über elftausend Kilometer entfernt.                                                       |
| **Teil 1 – Der Knall**                 |                                                                                                                                     |
| 05                                     | Indonesien, die Insel Sumbawa. Hier steht der Tambora, ein Vulkan, über viertausend Meter hoch.                                     |
| 06                                     | Am fünften April achtzehnhundertfünfzehn grollt er zum ersten Mal. Am Abend des zehnten April explodiert er.                        |
| 07                                     | Feuersäulen schießen in den Himmel. Glühende Lawinen aus Asche und Gas rasen die Hänge hinunter, bis ins Meer.                      |
| 08                                     | Den Knall hört man über tausend Kilometer weit. Auf Java hält man ihn für Kanonendonner und schickt Soldaten los.                   |
| 09                                     | Rund um den Berg wird es tagelang stockdunkel. Tag und Nacht sind nicht mehr zu unterscheiden.                                      |
| 10                                     | Danach ist der Tambora fast eineinhalb Kilometer niedriger. Wo der Gipfel war, klafft ein riesiger Krater.                          |
| 11                                     | Es ist der stärkste Vulkanausbruch der überlieferten Geschichte. Viel stärker als der berühmte Krakatau.                            |
| 12                                     | Mehr als zehntausend Menschen sterben sofort. Ganze Dörfer, sogar ein kleines Königreich, verschwinden unter der Asche.             |
| 13                                     | Und dann kommt der Hunger. Die Asche hat Felder und Brunnen begraben. Zehntausende weitere sterben.                                 |
| **Teil 2 – Der Schleier**              |                                                                                                                                     |
| 14                                     | Aber der Tambora schleudert nicht nur Asche hoch. Sondern vor allem etwas Unsichtbares: Schwefel.                                   |
| 15                                     | Rund sechzig Millionen Tonnen Schwefeldioxid steigen auf. Bis in die Stratosphäre, über vierzig Kilometer hoch.                     |
| 16                                     | Dort oben gibt es keinen Regen, der das Gas auswäscht. Es wird zu winzigen Tröpfchen.                                               |
| 17                                     | Die Winde tragen sie einmal um die ganze Erde. Wie ein dünner Schleier legen sie sich um den Planeten.                              |
| 18                                     | Und dieser Schleier wirft einen Teil des Sonnenlichts zurück ins All, bevor es unten ankommt.                                       |
| 19                                     | Im Durchschnitt wird es auf der Erde etwa ein halbes bis ein Grad kälter. Klingt wenig. Ist es aber nicht.                          |
| 20                                     | Denn ein Grad weniger im Durchschnitt heißt: kalte Tage, späte Fröste. Und Regen, Regen, Regen.                                     |
| 21                                     | Das Erstaunliche: Damals wusste niemand, woher die Kälte kam. Den Zusammenhang erkannte man erst rund hundert Jahre später.         |
| **Teil 3 – Der Sommer, der nicht kam** |                                                                                                                                     |
| 22                                     | Europa, Frühjahr achtzehnhundertsechzehn. Der Schnee will einfach nicht schmelzen.                                                  |
| 23                                     | Im Mai: Frost. Und in der Schweiz schneit es in diesem Jahr in jedem einzelnen Monat.                                               |
| 24                                     | Dazu regnet es. Wochenlang. Flüsse und Seen treten über die Ufer.                                                                   |
| 25                                     | In Süddeutschland ist es mitten im Sommer zwei bis drei Grad kälter als normal.                                                     |
| 26                                     | Auch in Nordamerika. In Neuengland schneit es im Juni, und im Juli und August gibt es Nachtfrost.                                   |
| 27                                     | Die Amerikaner nennen das Jahr später: Eighteen hundred and froze to death. Achtzehnhundert und erfroren.                           |
| 28                                     | Und in Asien? In China fallen Ernten aus. In Indien gerät der Monsun durcheinander.                                                 |
| **Teil 4 – Hunger**                    |                                                                                                                                     |
| 29                                     | Für die Bauern ist es eine Katastrophe. Das Getreide wird nicht reif. Es verfault auf den nassen Feldern.                           |
| 30                                     | Kartoffeln faulen in der Erde. Und der Wein wird so sauer, dass man ihn kaum trinken kann.                                          |
| 31                                     | Die Folge: Die Preise explodieren. Getreide kostet bald zwei-, dreimal so viel wie vorher.                                          |
| 32                                     | Im Winter und im Frühjahr achtzehnhundertsiebzehn wird der Hunger richtig schlimm.                                                  |
| 33                                     | Menschen strecken ihr Brot mit Sägemehl und Baumrinde. Sie essen Gras, Moos und Brennnesseln.                                       |
| 34                                     | Bettler ziehen von Dorf zu Dorf. In der Schweiz und in Süddeutschland sterben Tausende.                                             |
| 35                                     | Wer kann, packt seine Sachen. Aus Baden und Württemberg wandern Zehntausende aus.                                                   |
| 36                                     | Die einen ziehen die Donau hinunter nach Russland, bis in den Kaukasus. Die anderen über Holland nach Amerika.                      |
| 37                                     | Viele erreichen ihr Ziel nie. Auf den überfüllten Schiffen sterben unzählige an Krankheiten.                                        |
| **Teil 5 – Was blieb**                 |                                                                                                                                     |
| 38                                     | Doch das Jahr ohne Sommer hat nicht nur Leid hinterlassen. Sondern auch ein paar überraschende Spuren.                              |
| 39                                     | Juni achtzehnhundertsechzehn, eine Villa am Genfer See. Wegen des Dauerregens sitzen ein paar junge Engländer drinnen fest.         |
| 40                                     | Lord Byron schlägt einen Wettbewerb vor: Jeder soll eine Gruselgeschichte schreiben.                                                |
| 41                                     | Die achtzehnjährige Mary Shelley erfindet dabei eine Figur, die bis heute weltberühmt ist: Frankenstein.                            |
| 42                                     | Zweite Spur: Mannheim. Hafer ist so teuer, dass viele Pferde nicht mehr gefüttert werden können.                                    |
| 43                                     | Achtzehnhundertsiebzehn baut Karl Drais eine Laufmaschine. Zwei Räder, ein Lenker, kein Pferd. Der Urahn des Fahrrads.              |
| 44                                     | Ob der Hafermangel ihn wirklich darauf brachte, ist nicht sicher. Aber manche Forscher vermuten es.                                 |
| 45                                     | Und in Württemberg gründet König Wilhelm der Erste eine Landwirtschaftsschule. Damit so ein Hunger nie wieder passiert.             |
| 46                                     | Dazu ein großes Landwirtschaftsfest in Cannstatt. Daraus wird später: der Cannstatter Wasen.                                        |
| **Teil 6 – Heute**                     |                                                                                                                                     |
| 47                                     | Achtzehnhundertsiebzehn wird das Wetter endlich besser. Als die ersten vollen Erntewagen in die Dörfer rollen, feiern die Menschen. |
| 48                                     | Heute wissen wir: Ein einziger großer Ausbruch kann das Klima der ganzen Welt für Jahre verändern.                                  |
| 49                                     | Neunzehnhunderteinundneunzig zum Beispiel: Der Pinatubo auf den Philippinen. Danach war es weltweit messbar kühler.                 |
| 50                                     | Und der Tambora hat etwa dreimal so viel Schwefel ausgestoßen. Deshalb beobachten Forscher heute Vulkane auf der ganzen Welt.       |
| 51                                     | Ein einziger Vulkan. Und die halbe Welt hatte keinen Sommer.                                                                        |
