# 1816 – Das Jahr ohne Sommer (Testclip)

| Szene | Sprechertext                                                                                                  |
| ----- | ------------------------------------------------------------------------------------------------------------- |
| s1    | Stell dir vor, es ist Juni. Du willst ins Freibad. Und draußen … schneit es.                                  |
| s2    | Genau das ist passiert. Im Jahr achtzehnhundertsechzehn. Man nennt es: das Jahr ohne Sommer.                  |
| s3    | Schuld war ein Vulkan. Auf der anderen Seite der Welt: der Tambora, in Indonesien.                            |
| s4    | Im April achtzehnhundertfünfzehn explodierte er. Der stärkste Ausbruch der überlieferten Geschichte.          |
| s5    | Asche und Schwefel stiegen hoch in den Himmel. Und legten einen Schleier um die ganze Erde.                   |
| s6    | Es kam weniger Sonnenlicht an. Und in Europa wurde es kalt. Mitten im Sommer.                                 |
| s7    | Das Getreide verfaulte auf den Feldern. Brot wurde unbezahlbar. Und in Süddeutschland hungerten die Menschen. |
| s8    | Ein einziger Vulkan. Und die halbe Welt hatte keinen Sommer.                                                  |

Quellen: Oppenheimer 2003 (Progress in Physical Geography); Post 1977 (The Last Great Subsistence Crisis in the Western World).
Stimme: Piper „Thorsten“ (lokal, CC0).
